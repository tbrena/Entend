# Entend — Proposta comercial

Orçamento para o novo site institucional + loja virtual própria (livraria e
papelaria) da **Entend** (www.entend.com.br), solicitado por Eugenie Néri em 08/09/2026.

## Conteúdo

| Arquivo | O que é | Para quem |
|---|---|---|
| `proposta/orcamento-entend.html` | Proposta completa, formatada para leitura no celular e para virar PDF | Cliente |
| `proposta/orcamento-entend.md` | Mesma proposta em texto puro, fácil de editar | Uso interno / cliente |
| `proposta/mensagem-whatsapp.md` | Resposta curta pronta para enviar no WhatsApp | Cliente |
| `proposta/notas-internas.md` | Como os números foram construídos, o que ajustar antes de enviar | **Só interno — não enviar** |

## Antes de enviar

Os campos abaixo estão como marcador no HTML e no Markdown e precisam do seu dado real:

- `[SEU NOME / EMPRESA]`
- `[SEU E-MAIL]`
- `[SEU TELEFONE]`
- `[CNPJ]`

Confira também os valores dos módulos e o valor da hora avulsa
(R$ 180/h como está hoje) contra o seu posicionamento — ver `notas-internas.md`.

**Resumo do orçamento:** R$ 38.000, em 10 semanas, aberto em 6 módulos. Opção em
duas etapas: R$ 8.500 (site institucional) + R$ 29.500 (loja).

## Ressalva de apuração

`www.entend.com.br` não pôde ser acessado durante a preparação desta proposta
(bloqueio de rede do ambiente onde ela foi montada). O escopo assume reconstrução
do zero. Se o site atual tiver conteúdo, integrações ou histórico de SEO
relevantes, os números devem ser revistos na fase de descoberta — a proposta já
registra isso como premissa explícita.

## Gerar o PDF

O HTML tem folha de estilo de impressão. Abra `proposta/orcamento-entend.html`
no navegador e use Imprimir → Salvar como PDF (margens padrão, fundo ligado).
